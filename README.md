# ai-entry-inspector
AI-powered Taiwan entry item inspection system
# AI 入境物品檢查系統

## 專題目標
利用人工智慧辨識旅客攜帶的物品照片，
並提供台灣入境相關規定的查詢與提醒。

## 預計功能
- 上傳物品照片
- AI 影像辨識
- 顯示物品類別
- 提供入境注意事項

## 開發工具
- Python
- AI 影像辨識模型
- Streamlit
- GitHub
複製專題介紹

## 四、測試過程

### T01：行李圖片上傳

操作步驟：
1. 啟動 Streamlit 系統。
2. 上傳行李箱照片。
3. 確認系統是否成功接收圖片。

測試結果：成功上傳照片，功能正常。

### T02：AI 物品辨識

操作步驟：
1. 上傳包含衣服、橘子、手錶、玩偶等物品的行李照片。
2. 執行 AI 影像辨識。
3. 比對辨識結果與照片中的實際物品。

測試結果：
- 成功辨識橘子（orange）。
- 成功辨識手錶（watch）。
- 成功辨識玩偶類物品（plush toy）。
- 部分物品名稱與實際照片不符。
- 大耳狗泡澡球未被正確辨識。

發現問題：AI 模型存在誤判與漏判情形，仍需改善辨識準確度。

### T03：OCR 文字辨識

測試狀態：尚未測試。

原因：目前尚未使用清楚的商品標籤圖片進行文字辨識。

後續測試：上傳商品標籤圖片，比對 OCR 擷取文字與原始圖片是否一致。

### T04：手動輸入資料

操作步驟：
1. 選擇 AI 辨識出的橘子。
2. 略過 OCR 標籤上傳。
3. 進入手動輸入區域。
4. 準備輸入物品名稱、成分、產地、攜帶數量及攜帶目的。

測試狀態：測試中，尚待確認送出功能。

### T05：入境法規查詢

測試物品：橘子（新鮮水果）。

預期結果：系統能依照物品資訊提供臺灣入境相關檢疫規定及提醒。

測試狀態：尚未確認查詢結果。

## 五、發現問題與改善建議

1. **AI 辨識誤判：** 部分辨識名稱與照片中的實際物品不符，建議改善模型辨識準確度。
2. **AI 辨識漏判：** 部分實際存在的物品未被正確辨識，建議增加不同類型商品的測試資料。
3. **英文辨識結果：** 系統使用英文顯示部分物品名稱，建議增加中文翻譯，方便使用者理解。
4. **OCR 測試：** 後續需補充商品標籤圖片，確認文字辨識功能。

## 六、測試心得

透過本次測試，了解 AI 影像辨識系統雖然能夠自動偵測行李中的部分物品，但辨識結果仍可能出現錯誤或遺漏，因此需要透過實際圖片進行驗證。此外，系統提供手動補充資料的方式，讓使用者能在 AI 辨識不完整時自行修正資訊。後續將繼續測試 OCR 與入境法規查詢功能，確認整體系統的完整性與實用性。
