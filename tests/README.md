# AI 入境物品檢查系統－測試紀錄

## 一、測試目的

本測試主要確認 AI 入境物品檢查系統是否能正常上傳行李照片、辨識物品、讀取商品標籤文字，以及提供入境規定查詢功能。

透過實際操作，記錄系統功能是否正常，並找出 AI 辨識錯誤或需要改善的地方。

## 二、測試環境

- 作業系統：Windows
- Python 版本：3.13
- 開發工具：VS Code
- 網頁框架：Streamlit
- GPU：NVIDIA GeForce RTX 4050 Laptop GPU
- 測試方式：本機執行 Streamlit 網頁

| 編號 | 測試項目 | 預期結果 | 實際結果 | 測試狀態 |
|---|---|---|---|---|
| T01 | 行李圖片上傳 | 成功上傳並顯示圖片 | 成功上傳行李照片 | 通過 |

| T05 | 入境法規查詢 | 顯示物品相關入境限制及注意事項 | 尚未確認查詢結果 | 未測試 |

## 四、測試過程

### T01：行李圖片上傳

操作步驟：
1. 啟動 Streamlit 系統。
2. 上傳行李箱照片。
3. 確認系統是否成功接收圖片。

測試結果：成功上傳照片，功能正常。

### T02：AI 物品辨識

操作步驟：
1. 上傳包含衣服、橘子、手錶、玩偶等物品的行李照片。
2. 執行 AI 影像辨識。
3. 比對辨識結果與照片中的實際物品。

測試結果：
- 成功辨識橘子（orange）。
- 成功辨識手錶（watch）。
- 成功辨識玩偶類物品（plush toy）。
- 部分物品名稱與實際照片不符。
- 大耳狗泡澡球未被正確辨識。

發現問題：AI 模型存在誤判與漏判情形，仍需改善辨識準確度。

### T03：OCR 文字辨識

測試狀態：尚未測試。

原因：目前尚未使用清楚的商品標籤圖片進行文字辨識。

後續測試：上傳商品標籤圖片，比對 OCR 擷取文字與原始圖片是否一致。

### T04：手動輸入資料

**測試物品：** 橘子（Orange）

**測試步驟：**
1. 選擇 AI 辨識結果中的橘子。
2. 略過 OCR 標籤上傳。
3. 手動填寫物品名稱、成分、產地、數量及用途。
4. 點選「查詢入境規定」。

**實際結果：** 系統成功接收手動輸入資訊，並執行法規查詢。

**測試判定：通過。**

### T05 修正後重新測試（2026/11/04）

**測試物品：** 新鮮橘子

**原始問題：** 系統顯示「未知物品，無法判斷，請人工確認」，未正確呈現法規查詢結果。

**問題原因：**
- `regulation_checker.py` 與 `ui_components.py` 的資料欄位及狀態名稱不一致。
- UI 未支援 `needs_review` 狀態。
- 法規查詢結果未提供物品名稱，且判定摘要與詳細原因未正確顯示。

**修正內容：**
- 補上物品名稱欄位。
- 新增 `needs_review` 與 `insufficient_info` 狀態顯示。
- 調整 UI，使其能顯示 `summary` 與 `reasons`。

**重新測試結果：**
- 系統正確顯示物品名稱「橘子」。
- 成功找到植物產品相關規定。
- 顯示「已找到相關規定，需進一步確認」。
- 成功顯示判定原因及官方法規來源。

**測試判定：** 法規查詢與 UI 整合測試通過（PASS）。

**待改善事項：** 目前系統僅提供相關規定與人工確認提醒，尚未完整實作禁止或允許入境的自動判定功能。

## 五、發現問題與改善建議

1. **AI 辨識誤判：** 部分辨識名稱與照片中的實際物品不符，建議改善模型辨識準確度。
2. **AI 辨識漏判：** 部分實際存在的物品未被正確辨識，建議增加不同類型商品的測試資料。
3. **英文辨識結果：** 系統使用英文顯示部分物品名稱，建議增加中文翻譯，方便使用者理解。
4. **OCR 測試：** 後續需補充商品標籤圖片，確認文字辨識功能。

## 六、測試心得

透過本次測試，了解 AI 影像辨識系統雖然能夠自動偵測行李中的部分物品，但辨識結果仍可能出現錯誤或遺漏，因此需要透過實際圖片進行驗證。此外，系統提供手動補充資料的方式，讓使用者能在 AI 辨識不完整時自行修正資訊。後續將繼續測試 OCR 與入境法規查詢功能，確認整體系統的完整性與實用性。
